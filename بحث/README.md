# بحث: العادات الاجتماعية والدينية والأخلاقية عند العرب قبل الإسلام

مجلدٌ مستقل داخل المستودع لأرشفة البحث الموثَّق (لا يمسّ تطبيق إدارة المنتجات بأي تعديل).

## المحتوى

| الملف | الوصف |
|---|---|
| `بحث_العادات_الاجتماعية_والدينية_والأخلاقية_عند_العرب_قبل_الإسلام.docx` | **الملف النهائي للتسليم**: غلاف مزخرف، دليل استعمال، فهرس تلقائي (TOC)، مقدمة وخطة، ٣ أقسام × ٧ عادات (٢١ مبحثًا، ٦٨ شاهدًا موثقًا)، خاتمة، تنبيه الطبعات، ثبت المصادر، ٣ ملاحق |
| `citations_notes.md` | سجل التحقق من المصادر (٤٤ بندًا): كل جزء/صفحة تم التحقق منه في المكتبة الشاملة أثناء إعداد البحث |
| `docx_tools.py` | وحدة بناء مستند Word عربي (RTL): أنماط العناوين، صناديق الاقتباس والشعر، التنبيهات، الجداول، حقول الفهرس والترقيم، الترويسة |
| `content_front.py` | الغلاف + دليل الاستعمال + الفهرس + المقدمة + خطة البحث |
| `content_social.py` | القسم الأول: العادات الاجتماعية (٧ عادات) |
| `content_religious.py` | القسم الثاني: العادات الدينية (٧ عادات) |
| `content_moral.py` | القسم الثالث: العادات الأخلاقية (٧ عادات) + الخاتمة |
| `content_back.py` | تنبيه الطبعات + ثبت المصادر + الملاحق (أ: عبارات البحث، ب: الشواهد الشعرية، ج: معجم المصطلحات) |
| `build.py` | سكربت التجميع النهائي |
| `assets/cover_ornament.png` | الزخرفة الهندسية المستخدمة في الغلاف |

## إعادة البناء

```bash
pip install python-docx
python3 build.py
```

## منهج التوثيق في البحث

- كل عادة ≥ شاهدَين متنوعَين (رواية تاريخية / خبر أدبي / شعر / مثل / قرآن وتفسير / دراسة حديثة) برمز نوعٍ صريح.
- كل شاهد: النص حرفيًّا + التوثيق الكامل (مؤلف، كتاب، طبعة، جزء، صفحة) + سياق القصة + وجه الاستشهاد + عبارة بحث تعمل في المكتبة الشاملة.
- لم تُنسب صفحةٌ أو نصٌّ إلى مصدر إلا بعد التحقق منه؛ وما لم تُضبط صفحتُه صُرِّح بذلك وعُوِّض بموضع الباب/الآية/القصيدة مع عبارة البحث.
- تمييزٌ صريح بين الرواية التاريخية والنص الأدبي في درجة الدلالة، مع فقرة «موازنة الشواهد» في ختام كل عادة.

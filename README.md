# LUFLY Catalog Manager

نظام إدارة كتالوج منتجات بواجهة عربية، يعمل بـPHP 8.1 أو أحدث. على localhost يقرأ ويحفظ في ملفات JSON مستقلة، وعلى الاستضافة يستخدم قاعدة البيانات حسب الإعدادات.

## الوظائف

- عرض المنتجات والبحث والتجميع حسب بادئة الكود.
- تعديل الكود والوصف والحالة والماركة والملاحظات.
- رفع الصور واستبدالها وحذفها، مع الحفاظ على الصور المشتركة.
- عرض الصور بالحجم الكبير والتنقل بينها.
- التأكيد الفردي والجماعي، الأرشفة والاسترجاع والحذف.
- تغيير عنوان الموقع وألوانه.
- تسجيل الدخول عند ضبط كلمة مرور، وحماية طلبات التعديل بـCSRF.

## التشغيل على XAMPP

1. ضع المشروع داخل `C:\xampp\htdocs\manage_products_lufly`.
2. شغّل Apache. MySQL غير مطلوب في وضع الملفات المحلي.
3. تأكد من تفعيل إضافات PHP: `json` و`session` و`fileinfo`.
4. انسخ `.env.example` إلى `.env` واضبط `APP_PASSWORD` قبل إتاحة الموقع للآخرين.
5. افتح `http://localhost/manage_products_lufly/`.

إعدادات رفع الملفات في `php.ini` أو `.user.ini`:

```ini
upload_max_filesize = 12M
post_max_size = 128M
max_file_uploads = 30
memory_limit = 256M
```

الموقع لا يحتاج Python أو GD أو أي موديلات لمعالجة الصور. رفع الصور يعرض الملفات كما هي بدون تحسين أو تكبير تلقائي.

## التخزين

```ini
APP_STORAGE=auto
DB_DRIVER=mysql
```

- `auto`: يختار JSON على localhost/loopback وCLI، وقاعدة البيانات على الاستضافة.
- `files`: يجبر التخزين في الملفات.
- `database`: يجبر SQL. استخدمه صراحةً على الاستضافة، خصوصًا خلف reverse proxy.

ملف العمل المحلي: `data/local/catalog.json.php`، والنسخة السابقة: `catalog.json.php.backup.php`. الصور المرفوعة محليًا: `uploads/local/`. لا يتم تغيير `data/catalog.json` أو حذف صور الكتالوج الأصلية في وضع الملفات.

التعديلات القديمة في SQL لا تُنقل تلقائيًا ولا تُحذف. توجد أداة CLI اختيارية للتصدير إلى ملف JSON جديد. راجع [LOCAL_STORAGE.md](LOCAL_STORAGE.md) للتفاصيل والاستعادة والنسخ الاحتياطي.

لتشغيل MySQL تحتاج `pdo` و`pdo_mysql`. عدّل قيم `DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD` في `.env`. يدعم `config.local.php` تجاوز القيم:

```php
<?php
return [
    'storage_mode' => 'database',
    'host' => '127.0.0.1',
    'port' => 3306,
    'database' => 'lufly_catalog',
    'username' => 'root',
    'password' => '',
];
```

في أول تشغيل يتم إنشاء مخزن البيانات وقراءة الكتالوج المرفق عند الحاجة. إعادة التثبيت من الواجهة معطلة حتى لا تضيع التعديلات.

## الملفات الأساسية

| المسار | الوظيفة |
| --- | --- |
| `index.php` | الصفحات والواجهة ومسارات الطلبات |
| `app.php` | إدارة المنتجات والمرفقات والإعدادات |
| `login.php` | تسجيل الدخول |
| `config.php` | قراءة الإعدادات |
| `includes/catalog_storage.php` | تخزين JSON وواجهة التعامل المشتركة مع SQL |
| `includes/sidebar.php` | القائمة الجانبية |
| `database/schema.sql` | مخطط MySQL |
| `data/catalog.json` | كتالوج البداية: 715 منتجًا و1465 مرفقًا |
| `assets/catalog/` | صور الكتالوج الأصلية |
| `uploads/` | الصور المرفوعة؛ المحلي داخل `uploads/local/` |
| `tools/export_local_json.php` | تصدير اختياري من SQL إلى JSON جديد |
| `tools/import_excel.py` | بناء الكتالوج من ملفات Excel خارج دورة تشغيل الموقع |
| `tests/` | اختبارات إدارة الصور والبيانات والتخزين |

أداة Excel اختيارية وتحتاج Pillow عند استخدامها فقط، وليست مطلوبة لتشغيل الموقع.

## الأمان والنسخ الاحتياطي

- لا تترك `APP_PASSWORD` فارغًا إذا كان الموقع متاحًا لغيرك.
- احتفظ بنسخة من قاعدة البيانات و`data/local/` و`uploads/` قبل التحديث.
- لا تضع `.env` أو `config.local.php` أو نسخ الإعدادات في Git أو تشاركها.
- قبل النشر العام، اضبط HTTPS وصلاحيات الملفات ومنع الوصول إلى ملفات الإعدادات والبيانات في إعدادات خادمك.
- اختبارات التطوير وأدوات CLI ليست صفحات إدارة عامة؛ قواعد منع الوصول الموجودة في `tests/` و`tools/` مخصصة لـApache، وتحتاج ما يعادلها على خوادم أخرى.

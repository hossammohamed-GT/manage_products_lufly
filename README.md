# LUFLY Catalog Manager

نظام إدارة كتالوج منتجات LUFLY مبني بـ PHP وMySQL، بواجهة عربية RTL. بيانات المنتجات والمرفقات والإعدادات تُقرأ من قاعدة MySQL المحددة في ملف البيئة؛ لا توجد بيانات seed أو استيرادات تلقائية من ملفات محلية.

## المتطلبات

- PHP 8.1 أو أحدث.
- إضافة `pdo_mysql` للاتصال بقاعدة البيانات، و`fileinfo` لرفع الصور.
- إضافة GD اختيارية لميزة تحسين الصور.
- خادم MySQL متاح من الجهاز الذي يشغّل التطبيق.

## الإعداد

1. اضبط قيم `DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD` في `.env`. إذا لم يكن الملف موجودًا، ينشئه التطبيق من `.env.example`؛ راجع القيم قبل التشغيل على الخادم أو محليًا.
2. عيّن `APP_PASSWORD` لكلمة مرور تسجيل الدخول، ولا تضع ملف `.env` في Git.
3. استخدم قاعدة MySQL المطلوبة. إذا لم تكن الجداول موجودة، يحاول التطبيق إنشاء قاعدة البيانات والجداول من `database/schema.sql` عند أول تشغيل؛ يتطلب ذلك صلاحية الإنشاء. على الاستضافات التي لا تسمح بإنشاء قاعدة البيانات من التطبيق، أنشئ قاعدة البيانات والجداول يدويًا باستخدام `database/schema.sql`.
4. افتح `index.php` من خلال خادم PHP/Apache. يجب أن يكون مجلد `uploads/` قابلًا للكتابة لرفع الصور.

**لا ينشئ التطبيق منتجات أو مرفقات تلقائيًا.** قاعدة بيانات فارغة ستعرض كتالوجًا فارغًا؛ أضف بياناتك إلى MySQL بالطريقة التي تعتمدها.

## البيانات والصور

- المنتجات، المجموعات، حالات الأرشفة، التحقق، الإعدادات، وقائمة المرفقات مصدرها MySQL.
- يسجل جدول `media` بيانات المرفق ومسار الملف، وليس محتوى الصورة نفسه. تظل الملفات المشار إليها في `assets/catalog/` و`uploads/` مطلوبة على الخادم؛ حذف ملفات `assets/catalog/` سيكسر الصور التي تشير إليها قاعدة البيانات.
- تعرض بطاقات المنتجات الصور القابلة للعرض بالترتيب المسجل في MySQL، وتستخدم أول صورة متاحة. كما تُختار صورة المجموعة من أول مرفق قابل للعرض موجود فعليًا.
- الصور الجديدة تُحفظ في `uploads/`، ويُسجّل مسارها في جدول `media`.

## المميزات

- عرض المنتجات والبحث بالكود أو الوصف أو الماركة، مع التجميع حسب بادئة الكود.
- تعديل بيانات المنتجات وحالاتها، التحقق الفردي والجماعي، والأرشفة والاستعادة.
- رفع الصور والمرفقات واستبدالها وترتيبها وحذفها.
- إعدادات عنوان الموقع والألوان محفوظة في MySQL.
- واجهة عربية RTL، وحماية CSRF، واستعلامات PDO مُحضّرة.

## تحسين صورة موجودة

1. اضغط على صورة المنتج لفتحها بالحجم الكبير، ثم اختر **تحسين الصورة**.
2. قارن الأصل بالنسخة المحسّنة؛ التحسين خفيف للحدة والتباين ولا يولّد تفاصيل جديدة.
3. اعتمد النسخة صراحةً لاستبدال إحالة الصورة المحددة، أو ألغِ للاحتفاظ بالأصل.

يتطلب ذلك PHP GD ودعم نوع الصورة وصلاحية الكتابة في مجلد النظام المؤقت و`uploads/`. يدعم الصور الثابتة JPG وPNG وWebP، ولا يدعم GIF أو WebP المتحرك. المعاينة مؤقتة وخاصة بالجلسة؛ لا يتغير الأصل قبل الاعتماد.

## ملفات قاعدة البيانات والبيئة

- `database/schema.sql`: تعريف جداول MySQL، وليس dump لبيانات الكتالوج.
- `.env.example`: قالب إعدادات الاتصال وكلمة مرور التطبيق.
- `.env`: الإعدادات الفعلية لكل بيئة، ويجب أن يبقى محليًا وخارج Git.

الصور في `assets/catalog/` ملفات مطلوبة لمسارات المرفقات الموجودة في قاعدة البيانات؛ أما ملفات seed وملفات الاستيراد ونسخة dump المحلية فقد أزيلت.
